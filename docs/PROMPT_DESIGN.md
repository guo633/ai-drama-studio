# Prompt 流水线设计文档

## 设计目标

短剧创作不是一次调用能做好的事。把「一句话创意」直接丢给大模型，产出往往
结构混乱、前后矛盾。因此本项目把创作拆成 **5 步串行流水线**，每步聚焦一个
任务，上一步的产出作为下一步的上下文注入，形成可控的链式生成。

```
创意(idea) ──▶ ① 世界观 ──▶ ② 人物卡 ──▶ ③ 分集大纲 ──▶ ④ 第1集剧本 ──▶ ⑤ 分镜+AI提示词
                 │              │              │                │                 │
                 └──────────────┴──── 每步产出注入后续所有上下文 ────┴─────────────────┘
```

## 各步骤设计要点

### ① world_view 世界观设定
- **输入**：title / genre / style / idea
- **约束**：400 字以内、分点输出（时代地点 / 核心设定 / 规则 / 基调）
- **为什么**：先钉死世界观，后续人物和剧情才有统一的锚点，避免每集设定漂移

### ② characters 人物卡
- **输入**：① 的产出
- **约束**：主角/对手/关键配角三张卡，每卡固定字段（外在形象/真实身份/动机/成长弧线），要求人物之间有明确冲突关系
- **为什么**：固定字段强制模型补全「秘密与动机」，这是短剧反转的素材库

### ③ outline 分集大纲
- **输入**：① + ②
- **约束**：逐集「事件 + 钩子」格式；前三集必须完成困境建立、第一次爽点、悬念升级
- **为什么**：把短剧的付费转化逻辑（前三集定生死）直接写进 Prompt 约束

### ④ script 第 1 集剧本
- **输入**：③
- **约束**：标准剧本格式、约 1500 字（对应 2 分钟竖屏单集）、开场 10 秒进冲突、结尾强钩子
- **为什么**：只写第 1 集做「样品」，控制成本；格式对齐行业标准便于直接使用

### ⑤ storyboard 分镜与 AI 提示词
- **输入**：④
- **约束**：开篇 5 个镜头，每镜头附一段可直接使用的英文 AI 视频提示词（竖屏 9:16）
- **为什么**：打通「文字 → AI 视频生产」的最后一公里，也是本项目区别于普通「AI 写作」的亮点

## 模板工程（Prompt 即 Skill）

- 模板存储在数据库 `prompt_templates` 表，字段：`step`（唯一键）、`name`、`content`
- 变量用 `{var}` 插值，`_render` 使用 `format_map` + 缺失变量兜底空串，单变量缺失不会让整条流水线崩溃
- 前端提供可视化编辑器，`PUT /api/prompts/{step}` 保存后立即生效
- 这一设计与 Agent 工程中的 Skill 概念同构：**把领域经验固化成可复用、可版本化、可被他人改进的资产**

## 稳定性设计

- 每步完成即 `commit`：中断后已完成步骤不丢失，进度条精确反映实际状态
- 任何一步异常：任务置 `failed` 并记录错误信息落库，作品状态同步回滚，前端可见失败原因
- 超时 120 秒（长文本生成），温度 0.8 兼顾创意与稳定
